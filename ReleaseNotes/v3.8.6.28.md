# v3.8.6.28

## New features

  1. `StatEntity`        - add templated method to add any `container`
  1. `ECDF`              - add templated method to add any `container`
  1. `Ostap/Quantiles.h` - add `quantiles` methods for arbitrary quantiles `std::vector<double>` 
  1. `ECDF/WECDF`        - add `quantiles` methods for arbitrary quantiles `std::vector<double>` 
  1. Split `ADVAL_TORCH` into `Adam` and `LBFGS`
  1. Factor-out all methods for combining several p-values into single global p-value into separate module `pvalues.py`
  1. Add `random_python` and `random_root` helper functions to setup the random number seeds
  
## Bug fixes

  1. fix typos in `data_slice` (`use-frame`-branch)  and `SliceHelper`
  1. fix missing signature for `Ostap::Math::van_der_waerden`
  
## Backward incompatible

   1. remove Keras and Tensorflow
   1. split `PyTorch(Iterative/Density)Reweighter` into pairs of `PyTorch(Adam/LBGFGS)(Iterative/Density)Reweighter`
   1. remove `random_random`
